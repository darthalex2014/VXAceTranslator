# VXAceTranslator (Обновление 2026)

**Эффективный переводчик для игр на RPG Maker VX Ace.**  
Полностью написан на Ruby. Позволяет декомпилировать/компилировать все текстовые файлы `.rvdata2` в читаемый текст и обратно.

> **Обновление 2026:** Проект возрожден! Добавлен "Умный режим", исправлены имена скриптов и обновлены инструменты!

# Новые возможности (2026)
- **🚀 Умный режим (Smart Mode):** Командная строка больше не нужна! Просто поместите `.exe` в папку с игрой и запустите.
  - Если папки `Decompiled` нет -> Автоматическая расшифровка (если нужно) и **Декомпиляция**.
  - Если папка `Decompiled` есть -> **Компиляция** изменений обратно в файлы игры.
- **🛡️ Сохранение имен скриптов:** Исправлены ошибки со спецсимволами (типа `◢`, `★`, пробелы) в именах скриптов. Файлы сохраняются с безопасными именами, но оригинальные имена восстанавливаются при компиляции благодаря файлу `Scripts_Info.txt`.
- **🔓 Обновленный декриптор:** Теперь используется **RPGMakerDecrypter-cli v3.0.4** (ранее v2.0.0) для лучшей совместимости с зашифрованными архивами (`.rgss3a`).

# Основные функции
- **Автоматическая расшифровка:** Сам находит и распаковывает `Game.rgss3a`, если папка "Data" отсутствует.
- **Удобство для модов:** Поддержка добавления/удаления скриптов и вставка их в определенные позиции.
- **Безопасное редактирование:** Полная сериализация параметров общих событий.
- **Чистый вывод:** Организованная структура (Текстовые файлы + Ruby скрипты).
- **Режимы Indexless и Indexing:** Выбор между свободой редактирования и строгой совместимостью.

# Как использовать (Умный режим)

Рекомендуемый способ использования.

1. **Подготовка:** Скопируйте `VXAceTranslator.exe` и папку `Resources` в директорию игры (туда, где лежит `Game.exe`).
2. **Декомпиляция:** Запустите `VXAceTranslator.exe`.
   - Он распакует игру и создаст папку `Decompiled`.
   - *Важно:* Скрипты будут в `Decompiled/Scripts`. Не пугайтесь, если имена файлов выглядят упрощенно; настоящие имена сохранены в `Scripts_Info.txt`.
3. **Перевод:** Редактируйте `.txt` и `.rb` файлы в папке `Decompiled`.
4. **Компиляция:** Запустите `VXAceTranslator.exe` снова.
   - Он обнаружит папку `Decompiled` и соберет новую папку `Compiled/Data`.
5. **Финиш:** Скопируйте содержимое `Compiled/Data` в папку `Data` игры, чтобы применить перевод.

# Как собрать (Для разработчиков)

Если вы хотите изменить исходный код и собрать свой `.exe`.

### 1. Требования
Скачайте **Ruby 2.7.8 (Portable)**. Не используйте новые версии, они ломают совместимость форматов с RPG Maker VX Ace.
- **Ссылка:** [RubyInstaller-2.7.8-1-x64.7z](https://github.com/oneclick/rubyinstaller2/releases/download/RubyInstaller-2.7.8-1/rubyinstaller-2.7.8-1-x64.7z)

### 2. Установка
Распакуйте скачанный архив в корневую папку проекта. Скрипт сборки умный и поддерживает любые имена папок:
- `ruby` (Рекомендуется)
- `rubyinstaller-2.7.8-1-x64`
- `rubyinstaller-2.7.8-1-x64\rubyinstaller-2.7.8-1-x64` (Если распаковали слишком глубоко)

### 3. Сборка
Просто запустите **`MakeExe.bat`**.
Он найдет ваш Ruby, скомпилирует гемы и создаст `VXAceTranslator.exe`.

# Синтаксис вставки скриптов
Чтобы вставить новый скрипт без перенумерации всего списка:
1. Назовите файл: `Index+1 - ИмяСкрипта.rb`
2. Пример: Чтобы вставить скрипт после номера 10, назовите его `10+1 - MyNewScript.rb`.

# Режимы Indexless и Indexing
- **Indexless (По умолчанию):** Пересоздает события с нуля. Хорош для глобального редактирования.
- **Indexing:** Патчит оригинальные события по ID. Хорош для совместимости, если вы меняете только текст.
